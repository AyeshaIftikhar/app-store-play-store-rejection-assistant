```
## Pre-Submission Verification

- [ ] All app code changes implemented and merged
- [ ] Store console configuration updated
- [ ] Metadata changes applied
- [ ] Privacy/legal documents updated
- [ ] All testing steps completed successfully
- [ ] Build compiled and uploaded to store
- [ ] Reviewer response drafted
- [ ] Response submitted in {Resolution Center / Play Console}
```

## Pro Tips

1. **Order matters** — some fixes depend on others (e.g., update the privacy policy before updating the Data Safety form)
2. **One checklist per rejection** — if multiple issues are present, create separate checklists for each
3. **Include verification steps** — each code change should have a corresponding testing step
4. **Track version numbers** — note which version each fix will ship in
5. **Date-stamp completion** — note when each item was completed
