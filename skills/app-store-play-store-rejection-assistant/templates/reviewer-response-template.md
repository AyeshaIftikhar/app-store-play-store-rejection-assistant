# Reviewer Response Template

Use this template when drafting a response to an Apple App Store or Google Play reviewer. Customize each section based on the specific rejection.

```
Dear {App Store Review Team / Google Play Review Team},

Thank you for your review of {App Name}. We have addressed the issue(s) identified below:

{For each issue, include:}

{Issue Number}. {Policy Reference / Issue Description}
- {Specific change made}
- {Specific change made}
- {Specific change made}

---

{Optional: Specific technical details if requested}

---

{For Apple — if binary was uploaded:}
An updated binary ({version number}) reflecting the changes above has been uploaded to App Store Connect.

{For Google Play — if APK/AAB was uploaded:}
An updated build ({version number}) reflecting the changes above has been uploaded to the Play Console.

Please let us know if any additional information is needed.

Best regards,
{Developer Name / Team Name}
```

## Guidelines

1. **Be specific** — name exact changes, do not use vague language like "improved" or "enhanced"
2. **Be concise** — reviewers read hundreds of responses; keep each issue to 2-3 bullet points
3. **Do not argue** — if you disagree with the rejection, address it factually without confrontational language
4. **Do not make false claims** — only state changes you have actually made
5. **Do not rush** — if you need more time to implement the fix, say so rather than submitting incomplete changes
6. **Do not blame third parties** — even if an SDK or library caused the issue, take responsibility for fixing it

## Apple-Specific Notes

- Submit the response via App Store Connect > My Apps > {App} > App Review > Resolution Center
- You can upload a new binary directly from the Resolution Center
- If you need to provide a demo account, include it in the response
- If you need to provide a video, upload it to a shareable link and include the URL

## Google Play-Specific Notes

- Submit the response as part of the appeal process in Play Console
- For suspensions, use the Appeal form in Play Console > Policy > App appeals
- Include the exact version code of the updated build in your response
- For Data Safety issues, ensure the form is fully updated before submitting the response
